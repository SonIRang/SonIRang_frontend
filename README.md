# SonIRang_frontend

# React

React와 styled-components로 만든 간단한 웹 애플리케이션입니다.  
프로젝트는 Create React App(CRA)으로 시작되었습니다.

## 📁 프로젝트 구조

/ 👉 메인 페이지 (MainPage)
/meeting 👉 미팅 페이지 (MeetingPage)

## 🛠 사용 기술

- React
- React Router DOM
- styled-components
- Create React App

## 🚀 실행 방법

1. 의존성 설치
npm install

2. 개발 서버 실행
npm start

## 🧪 테스트 방법

1. ### 회원가입

   * 이메일 인증은 필수입니다.
     회원가입 후 전송된 이메일에서 `?token=` 뒤의 토큰 값을 복사해 인증창에 붙여넣어 주세요.

2. ### 로그인

   * 로그인 후 **페이지를 새로고침** 해주세요.
   * 개발자 도구(Network 탭)에서 **웹소켓 서버에 연결되었는지 확인**한 후 통화 테스트를 진행할 수 있습니다.

3. ### 친구 추가

   * 친구의 **이메일(이미 가입된 사용자)** 을 검색하여 추가할 수 있습니다.
   * 친구 추가 후 **페이지를 새로고침하면 목록에 반영**됩니다.

4. ### 전화 통화

   * 친구 목록 또는 친구 프로필에서 **전화 걸기** 버튼을 클릭하면 `/meeting` 페이지로 이동합니다.
   * 수신자도 **로그인을 끝낸 메인 화면에서 새로고침 후 웹소켓 서버에 연결**되어 있어야 합니다.
   * 발신자가 **"통화 시작" 버튼을 클릭하면**, 수신자 메인 화면에 **수신 알림이 표시**됩니다.
   * 수신자가 수락 후 입장한 `/meeting` 페이지에서 다시 **"통화 시작" 버튼을 클릭하면** 영상 통화가 시작됩니다.
